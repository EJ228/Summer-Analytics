# Summer Analytics

Welcome to the Summer Analytics repository! This repository contains course materials, datasets, and notebooks for the Summer Analytics program.

## Contents

- **SA2025W1.ipynb** — Week 1 Jupyter notebook with data analysis exercises
- **cars.csv** — Dataset used in the Week 1 notebook

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/Summer-Analytics.git
   ```
2. Install the required dependencies (e.g., pandas, numpy, matplotlib).
3. Open the notebook in Jupyter:
   ```bash
   jupyter notebook SA2025W1.ipynb
   ```

## Requirements

- Python 3.x
- Jupyter Notebook
- pandas
- numpy
- matplotlib
